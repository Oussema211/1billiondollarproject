Place your app icon (icon.ico for Windows, icon.icns for Mac, icon.png for Linux) in this folder.
For Windows: Use a .ico file (256x256 recommended)
For Mac: Use an .icns file
For Linux: Use a .png file (256x256 recommended)

You can convert images to .ico format using online tools like:
https://convertio.co/ico-converter/
https://icoconvert.com/
